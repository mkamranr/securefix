Fix validation commands

Before a fix is offered, the app applies it to a copy of the commit and runs these commands in the repository root. A step fails on a non-zero exit code. In the re-scan command, {files} becomes the changed files, and the command must fail while the finding is still there.

These commands run on this server with the app's permissions, which is why only administrators can set them.
