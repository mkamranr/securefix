Register the app in GitLab

  1. In GitLab, open Admin › Applications › New application (as a GitLab administrator).
  2. Name it SecureFix, and set the redirect URI to {{ oauth.callback }}.
  3. Tick Trusted (no extra consent screen) and Confidential, and the scopes api and read_repository.
  4. Save, then copy the Application ID and secret into this form.

A profile is created on each person's first sign-in; a Windows profile with the same username is reused.
